# Maintainers

GravityBridge is maintained by [@seamas0825-lab](https://github.com/seamas0825-lab).

Authentication, credential handling, Codex mutation and restoration, dependency
installation, packaging, and GitHub Actions are security-sensitive surfaces.
Changes to them require an explicit review for secret handling, destination
control, least privilege, reversibility, and fail-closed behavior.

The project is derived from OpenCodex. Upstream ownership and attribution are
recorded in `NOTICE` and `LICENSE`; upstream maintainers are not responsible
for GravityBridge support or releases.
